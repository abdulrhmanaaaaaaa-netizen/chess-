# NIGHT RUSH 3D — لعبة سباق شوارع

لعبة قيادة ثلاثية الأبعاد تعمل في المتصفح، ومهيأة للهاتف والكمبيوتر.

## ما الموجود داخل النسخة؟

- عالم مدينة ثلاثي الأبعاد: طريق متعدد الحارات، مبانٍ، أرصفة، نخيل، أعمدة إنارة، لوحات طريق وجسور.
- أربع نسخ لونية من سيارة SAQR X1، باستخدام ملف المجسم الحقيقي `assets/Saqr_X1.glb` داخل مشهد القيادة، مع عجلات منفصلة تدور وتوجيه للعجلات الأمامية.
- سيارات مرور تتحرك أمامك، واصطدامات بسيطة عند الاقتراب منها.
- مقود لمس يمكن سحبه يمينًا ويسارًا، ودواسة تسارع وفرامل وزر نيترو.
- عداد سرعة، ناقل حركة، مسافة، مؤقت، تغيير زاوية الكاميرا، وإيقاف مؤقت.
- ثلاث صور أصلية مرفقة للغلاف والمرآب وشاشة نهاية الجولة.

## التشغيل على الهاتف

**الطريقة الأسهل: GitHub Pages**

1. نزّل ملف ZIP وفك الضغط عنه.
2. ارفع محتويات مجلد `night-rush-3d` إلى جذر مستودع GitHub؛ يجب أن يكون `index.html` ظاهرًا مباشرة في الصفحة الرئيسية للمستودع، وبجواره `style.css` و`game.js` ومجلد `assets` الذي يحتوي على `Saqr_X1.glb` والصور.
3. افتح إعدادات المستودع ثم **Pages**.
4. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واضغط **Save**.
5. افتح رابط GitHub Pages بعد نشر الموقع.

يمكنك أيضًا تشغيلها عبر أي خادم محلي يدعم ملفات ES Modules. فتح `index.html` مباشرة من مدير الملفات قد لا يعمل بسبب قيود المتصفح على وحدات JavaScript.

## التحكم

| التحكم | الوظيفة |
|---|---|
| سحب المقود | التوجيه يمينًا ويسارًا |
| دواسة تسارع | زيادة السرعة |
| فرامل | خفض السرعة |
| N₂O | دفعة نيترو مؤقتة |
| زر الكاميرا | التبديل بين كاميرا المطاردة وكاميرا المقدمة |
| زر الإيقاف | إيقاف اللعبة مؤقتًا |

على الكمبيوتر: `W` أو السهم للأعلى للتسارع، و`A/D` أو الأسهم للتوجيه، و`Space` للفرامل، و`Shift` للنيترو، و`C` لتغيير الكاميرا، و`Esc` للإيقاف المؤقت.

## ملاحظات تقنية

- يعتمد محرك العرض ثلاثي الأبعاد على Three.js المحمّل من CDN، لذلك يلزم اتصال بالإنترنت عند تشغيل اللعبة.
- سيارة اللاعب تُحمّل من ملف GLB المرفق وتظهر كمجسم ثلاثي الأبعاد قابل للقيادة. سيارات المرور الأخرى تُنشأ بخفة بواسطة Three.js. صور الغلاف والمرآب وشاشة النهاية مخصّصة للواجهات وليست مجسمات سيارات.
- هذه نسخة أولية قابلة للتطوير، وليست لعبة متجر مكتملة بمحاكاة قيادة واقعية أو نظام أونلاين.
